## 核心特性

### 一、个性化
- ✅ **电子名片**：头像可上传、字段自由编辑、一键复制分享
- ✅ **全局主题**：6 种主题色切换、背景色 + 背景图自定义、字体切换（系统/苹方/宋体/楷体/手写体）、字号 12-20px 调节

### 二、核心业务
- ✅ **班级课表**：常规班/暑假班分类管理，支持导出 CSV
- ✅ **学员档案**：姓名/年级/班次/薄弱项/标签/家长沟通/请假补课/月考·期中·期末·单元测
- ✅ **成绩走势**：折线图自动绘制，不同类型考试分色显示
- ✅ **WPS 导出**：SheetJS 引擎，导出标准 .xlsx（兼容 WPS）
- ✅ **家长沟通**：时间线 + 4 套默认话术模板 + 待回访清单
- ✅ **课时管理**：消课/补课/请假登记，自动同步学员课时
- ✅ **教学素材库**：试卷/讲义/答题模板/练习题归档
- ✅ **工作看板**：待办/进行中/已完成，拖拽切换状态（移动端可横向滑动）

### 三、AI 思维导图
- ✅ 输入"内容/重难点/课时安排" → 自动生成结构化导图
- ✅ 自绘 SVG：拖拽节点、双击编辑、右键添加子节点、PNG 导出
- ✅ 移动端：自动缩放，画布可滚动

### 四、数据管理（重点）
- ✅ **IndexedDB 本地数据库**：清除浏览器缓存数据不丢、隔天打开仍可访问
- ✅ **localStorage 镜像**：秒开体验
- ✅ **一键备份**：下载完整 JSON 文件
- ✅ **数据恢复**：上传 JSON 一键还原
- ✅ **夸克网盘永久备份**：备选方案，链接已嵌入

### 五、全局悬浮球
5 个快捷入口：新建学员、新建沟通、打开课表、调取话术、新建备课导图

### 六、附加工具
- ✅ **全局搜索**：按姓名/关键词检索全部数据
- ✅ **快捷剪贴板**：保存高频沟通文案，一键复用
- ✅ **课堂计时器**：开始/暂停/重置/4 档预设
- ✅ **桌面便签**：自动保存

### 七、🚫 禁止空间关停（防休眠）
应用通过 **三重机制** 保证常驻运行，不被浏览器/系统休眠：

1. **Wake Lock API**（推荐）：请求屏幕唤醒锁，防止手机熄屏或浏览器进入节能模式
2. **Web Audio 心跳**：每 25 秒播放静音音频，欺骗浏览器认为页面正在播放媒体
3. **Service Worker**：注册后台脚本，浏览器不会因前台页面空闲而回收资源
4. **localStorage 心跳**：每 25 秒写入时间戳，触发数据活动

页面左下角有 **"● 运行中"** 绿色指示器，实时显示运行状态：
- 🟢 绿色脉冲 = 正常运行
- 🟡 黄色常亮 = 页面被切到后台（仍尝试保持）

### 八、响应式（手机/电脑双适配）
- ✅ **320px ~ 2560px** 全屏适配
- ✅ **断点 1（≤1024px）**：思维导图/名片/看板转为单列
- ✅ **断点 2（≤768px）**：侧边栏汉堡菜单、弹窗从底部弹出、表格横向滚动
- ✅ **断点 3（≤480px）**：字号收紧、计时器按钮自适应、输入字号防 iOS 缩放
- ✅ **断点 4（≤360px）**：极小屏隐藏顶栏搜索、底部字号缩小
- ✅ **iOS 安全区适配**：使用 `env(safe-area-inset-bottom)` 避开 Home Indicator

## 部署方式

### 方式 1：本地部署（最稳定）
1. 将整个 `yuwen-teacher` 文件夹放到任意位置
2. 用浏览器打开 `index.html` 即可使用
3. **数据完全保存在浏览器本地，无需服务器**

### 方式 2：静态网站部署
- 支持任意静态托管：Netlify / Vercel / GitHub Pages / 阿里云 OSS / 腾讯云 COS
- 上传 `index.html`、`styles.css`、`app.js`、`sw.js`、`vendor/` 整个目录
- **必须用 HTTPS** 才能启用 Service Worker 和 Wake Lock API

### 方式 3：本地 HTTP 服务
```bash
cd yuwen-teacher
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 部署后首次使用

1. 打开页面，系统自动创建 IndexedDB 数据库 + 注册 Service Worker
2. 左下角出现 **"● 运行中"** 指示器
3. 顶部使用说明有详细引导
4. 建议每周使用「数据备份 → 一键备份」导出 JSON
5. 将 JSON 上传至夸克网盘做长期保存

## 技术栈

- 纯原生 HTML/CSS/JavaScript（零依赖框架）
- IndexedDB 持久化
- SheetJS 0.18.5（WPS/Excel 导出）
- 自绘 SVG 思维导图（无第三方依赖）
- Canvas 自绘折线图
- Service Worker + Wake Lock API + Web Audio（防休眠）
- Page Visibility API（运行状态检测）

## 兼容性

- Chrome / Edge 90+（推荐，支持完整 Wake Lock）
- Firefox 84+（部分支持 Wake Lock）
- Safari 16.4+（iOS 16.4 起支持 Wake Lock）
- 移动端浏览器（iOS Safari、Android Chrome）
- 屏幕宽度 320px ~ 2560px 全适配

## 注意事项

- **HTTPS 要求**：Wake Lock API 和 Service Worker 需要 HTTPS 协议。localhost 也算安全上下文可用。
- **首次打开**：可能需要几秒钟初始化 IndexedDB 和注册 Service Worker
